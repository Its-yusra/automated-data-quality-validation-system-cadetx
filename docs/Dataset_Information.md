# Dataset Information

## Dataset Name

Diabetes 130-US Hospitals for Years 1999-2008

## Source

UCI Machine Learning Repository

## Domain

Healthcare

## Dataset Size

- Instances: 101,766
- Features: 47

## Data Types

The dataset contains categorical and integer features.

## Missing Values

The dataset contains missing values.

## Why It Is Useful for This Project

The dataset provides several situations that can be investigated
during data-quality analysis, including:

- missing values
- duplicate records
- categorical values
- data-type consistency
- unique/cardinality analysis
- identifier columns
- demographic fields
- unusual or suspicious values

The dataset will be used for educational data-quality profiling,
cleaning and validation. No private patient data will be added.
